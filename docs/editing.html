Editing

Three views

The shortcut toggles a view on and off; choosing it from the menu always switches to it. Undo and redo work across views: an edit made in the source is one undo step in the rendered view.

Source Code Mode has its own preferences (line numbers, soft wrap, current-line highlight, visible whitespace, font size): see Settings.

Formatting

Select text and use the Format menu or a shortcut, or type the Markdown yourself — writing **word** turns bold as soon as you close it.

The formatting toolbar above the page offers the same commands; View → Toolbar hides it.

Headings, lists and quotes

  • Paragraph → Heading 1–6: Cmd+1 … Cmd+6; Paragraph: Cmd+0. Or start a line with #, ##, … and a space.
  • Start a line with - for a bullet list, 1. for a numbered list, - [ ] for a task, > for a quote. The Paragraph menu has the same commands.
  • Tab indents a list item, Shift+Tab outdents it, and Enter on an empty item ends the list. Click a task box to tick it.
  • Alt+↑ / Alt+↓ move the current block or list item up or down.

Tables

Paragraph → Table → Insert Table… (Opt+Cmd+T, Ctrl+Shift+T on Windows and Linux) asks for the size: point at the grid to pick up to 6 columns and 9 rows, or type the numbers for a larger table, then press Enter or click Insert (Esc cancels). The size counts the rows below the header; a header row is always added. The new table goes after the block the caret is in (inside a list item or quote, it stays there), and the caret waits in the first header cell. The same command is in the toolbar's More menu and in the document's context menu. Undo removes the whole table in one step.

Click into a cell and type; Tab moves to the next cell, empty cells included. Paragraph → Table also adds and deletes rows and columns, moves them, and aligns a column. A new row or column starts empty, with the caret in it, ready for typing. Add Row Below is Cmd+Enter (Ctrl+Enter).

Code blocks

Fenced code blocks (three backticks and a language name) are syntax-highlighted. Click the language label to change the language, or the copy button to copy the code. View → Highlight Code turns highlighting off for the session.

Links

Links open with Cmd-click (Ctrl-click on Windows and Linux), so a plain click can place the caret inside the link text. Links between notes in a folder are covered in Folders and vaults.

Images

Paste an image (for example a screenshot) or drag image files into a document. Markise copies the image into a folder next to the note — assets by default — and inserts a Markdown image with a relative path. Pasted image data is saved as Pasted image <date and time>.png.

  • Dropping other files inserts a link to them; whether they are copied too is a preference.
  • Pasting an image URL inserts it as an image.
  • Undo removes the inserted Markdown but never deletes the copied file.
  • In a document that has never been saved, images go to Markise's own app-data folder (user-images, next to the settings file) and are linked with absolute paths.
  • Limits: 50 MiB per file; clipboard images up to 100 megapixels.

Where images go is set in Preferences → Files & Images; see Settings. In an Obsidian vault, the vault's attachment folder is used when it is set.

Find and replace

The find bar has toggles for Match case (Aa), Whole word and regular expressions (.*). With regular expressions, the replacement can use captured groups as $1 or ${name}; write $$ for a literal dollar sign. Replace All is one undo step, and the bar offers Undo Replace All right after it.

Find searches the Markdown source of the current document in every view, link addresses included; a match hidden by formatting can be shown with Show in Source. Other files are not searched: search across a folder is not available in the beta.

Copy and paste

Copy and cut put the Markdown source of the selection on the clipboard. Paste inserts text as plain text; rich text copied from other applications is not converted to Markdown yet.

Typing helpers

Preferences → Editor controls auto-pairing of brackets and quotes (on by default), auto-pairing of Markdown markers, and smart punctuation (curly quotes, dashes), which is off by default. See Settings.
