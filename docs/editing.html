Editing

Three views

The shortcut toggles a view on and off; choosing it from the menu always switches to it. Undo and redo work across views: an edit made in the source is one undo step in the rendered view.

Source Code Mode has its own preferences (line numbers, soft wrap, current-line highlight, visible whitespace, font size): see Settings.

Formatting

Select text and use the Format menu or a shortcut, or type the Markdown yourself — writing **word** turns bold as soon as you close it.

The formatting toolbar above the page offers the same commands; View → Toolbar hides it.

Headings, lists and quotes

  • Paragraph → Heading 1–6: Cmd+1 … Cmd+6; Paragraph: Cmd+0. Or start a line with #, ##, … and a space.
  • Start a line with - for a bullet list, 1. for a numbered list, - [ ] for a task, > for a quote. The Paragraph menu has the same commands.
  • Tab indents a list item, Shift+Tab outdents it, and Enter on an empty item ends the list. Click a task box to tick it.
  • Alt+↑ / Alt+↓ move the current block or list item up or down.

Callouts

A quote whose first line starts with [!name] is a callout: a coloured block with an icon and a title.

> [!warning] Mind the step
> The body, any Markdown.

> [!success]- Starts closed
> Hidden until opened.

> [!info]+ Starts open
> Can be closed.
  • Type: the name decides the colour and the icon, in any letter case. Known names are note, info, tip, hint, important, success, check, done, question, help, faq, warning, caution, attention, failure, fail, missing, danger, error, bug, example, quote, cite, abstract, summary, tldr and todo. Any other name of letters, digits, - and _ shows in the note style.
  • Title: the text after the tag, with inline Markdown. Without one, the title is the name with a capital first letter.
  • Folding: - after the tag starts the callout closed, + starts it open, and without either it cannot be folded. Click the header to open or close it. A caret or a search hit going inside opens it, and closing it moves the caret past it. This is only how you see it for now: the file does not change, nothing is marked as unsaved, there is nothing to undo, and the callout starts as written when you open the file again.

Typing [!name] as the first line of a quote makes the callout and puts the caret in its body. Edit the title by moving up from the body with the arrow keys. To add a title or a fold mark to a callout that has none, use Source Code Mode, which always shows the text as written. Backspace at the start of the title, or of the body of a callout without a title, removes the tag and leaves a plain quote.

Callouts can be nested and can sit in lists. Exports show them too: see Export.

Tables

Paragraph → Table → Insert Table… (Opt+Cmd+T, Ctrl+Shift+T on Windows and Linux) asks for the size: point at the grid to pick up to 6 columns and 9 rows, or type the numbers for a larger table, then press Enter or click Insert (Esc cancels). The size counts the rows below the header; a header row is always added. The new table goes after the block the caret is in (inside a list item or quote, it stays there), and the caret waits in the first header cell. The same command is in the toolbar's More menu and in the document's context menu. Undo removes the whole table in one step.

Click into a cell and type; Tab moves to the next cell, empty cells included. Paragraph → Table also adds and deletes rows and columns, moves them, and aligns a column. A new row or column starts empty, with the caret in it, ready for typing. Add Row Below is Cmd+Enter (Ctrl+Enter).

Between blocks

To write a paragraph between two blocks that sit next to each other without one — two tables, a table and a code block, a formula, a diagram, an image, a horizontal line, an HTML block, or the end of a quote or list — click in the space between them, or press ↓ on the last line of the first block or ↑ on the first line of the second (← and → stop there too). The caret waits on an empty line; nothing is written to the file until you type, and moving away leaves the file unchanged. Enter at the end of a table's last row also goes there. What you type becomes a paragraph of its own, with blank lines around it so neither neighbour takes it in.

Code blocks

Fenced code blocks (three backticks and a language name) are syntax-highlighted. Click the language label to change the language, or the copy button to copy the code. View → Highlight Code turns highlighting off for the session.

Links

Links open with Cmd-click (Ctrl-click on Windows and Linux), so a plain click can place the caret inside the link text. Links between notes in a folder are covered in Folders and vaults.

Images

In the rendered view an image shows at its own size at most, within the column and 400 points high, scaled with the window's zoom. The file, the Markdown and exports stay as they are, and a double click or the expand button shows the image whole.

Paste an image (for example a screenshot) or drag image files into a document. Markise copies the image into a folder next to the note — assets by default — and inserts a Markdown image with a relative path. Pasted image data is saved as Pasted image <date and time>.png.

  • Dropping other files inserts a link to them; whether they are copied too is a preference.
  • Pasting an image URL inserts it as an image.
  • Undo removes the inserted Markdown but never deletes the copied file.
  • In a document that has never been saved, images go to Markise's own app-data folder (user-images, next to the settings file) and are linked with absolute paths.
  • Limits: 50 MiB per file; clipboard images up to 100 megapixels.

To look at an image closely, open it in a full-window view: double-click it, or hover it and press the expand button in its corner. It opens fitted to the window, at its full resolution even if the document shows a reduced copy. The mouse wheel or a pinch zooms around the pointer, dragging pans, and +, - and 0 zoom in, zoom out and fit it again. Esc or a click outside the image closes the view. A single click still places the caret, and Cmd/Ctrl+click on an image inside a link still follows the link.

To change an image, hover it. Replace… opens the image picker and changes only the path: the description and the title stay, and an image from anywhere, a web address included, can be replaced. Edit… opens a small window with the description and the path as written. Each is one undo step, and undo never deletes a copied file. A reference image (![text][label]) has its path in the definition, so it has neither button; a picture in a block's native view belongs to the block's form; and comments shown as No Markup or Original leave the document read-only.

The image picker shows thumbnails of the images in the document's folder and its subfolders, the nearest first, up to 2000 images and six levels down; a note says when there are more. Type to search by name, use the arrow keys and Return or double-click to choose, Esc to close. The current image is selected, and a dot marks images the document already uses. An image in the folder is linked where it is. Browse… opens the system's file dialog, and a file dropped on the window is added to the list; both go by the same rules as a drop. A document that has never been saved has no folder, so it goes straight to the file dialog. A block's form uses the same picker for Choose file.

Where images go is set in Preferences → Files & Images; see Settings. In an Obsidian vault, the vault's attachment folder is used when it is set.

Find and replace

The find bar has toggles for Match case (Aa), Whole word and regular expressions (.*). With regular expressions, the replacement can use captured groups as $1 or ${name}; write $$ for a literal dollar sign. Replace All is one undo step, and the bar offers Undo Replace All right after it.

Find searches the Markdown source of the current document in every view, link addresses included; a match hidden by formatting can be shown with Show in Source. Other files are not searched: search across a folder is not available in the beta.

Copy and paste

Copy and cut put the Markdown source of the selection on the clipboard. Paste inserts text as plain text; rich text copied from other applications is not converted to Markdown yet.

Typing helpers

Preferences → Editor controls auto-pairing of brackets and quotes (on by default), auto-pairing of Markdown markers, and smart punctuation (curly quotes, dashes), which is off by default. See Settings.
