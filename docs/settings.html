Settings

Open Preferences… with Cmd+, (Ctrl+,; on Windows and Linux it is at the end of the Edit menu). Changes apply immediately. The search field at the top finds a setting by name.

Most sections have a Reset to Defaults button at the bottom (Editor, Markdown, Appearance, Source Mode, Files & Images); it asks before resetting.

Export

There are no export settings in the beta: each format uses its built-in options, and Pandoc is found automatically. See Export.

The settings file

All preferences are stored in one JSON file:

You can edit it by hand while Markise is closed; changes made while it runs are read at the next start. Keys Markise does not know are kept. If the file cannot be read, Markise starts with the defaults and does not overwrite the file until you change a setting. Several running instances do not overwrite each other's changes.
