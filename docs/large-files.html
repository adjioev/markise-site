Large files

Markise is built to open and edit large Markdown files — logs, exports, generated documentation — without freezing. Only the part of a document that is on screen is laid out and drawn.

Opening in two steps

When you open a file with 4 MiB or more of text, Markise shows the first part (about 200 KiB) right away and loads the rest in the background. You can read, scroll and type in the first part meanwhile; the status bar says "Loading the rest of the file…" until the whole file is in. Reloading a file that is already open does not use the two steps.

Measurements

Recorded on 3 November 2026 on an Apple M-series Mac, release build, headless through the real app, with 100 MiB test documents:

"Headless" means the app ran without a window: the times do not include the operating system's window, GPU and compositor work, so on screen they are longer. Your machine and your files will give different numbers. The full method and table are in ADR 0017.

While the rest is loading

If the rest of the file cannot be loaded, Markise keeps the first part on screen, says so in a banner, and disables saving so the file on disk is never replaced by a partial copy.

Tips

  • Memory use grows with the file: in the test above, the heap peaked at about 270–480 MB for the 100 MiB documents.
  • Files that are not valid UTF-8 open with replacement characters and cannot be saved, so they are never damaged; draft backups are not made for them either.
