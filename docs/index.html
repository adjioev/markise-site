Markise user guide

Markise is a Markdown editor for macOS, Windows and Linux. You write in the rendered page, in the plain Markdown source, or in both side by side; the file on disk is always plain Markdown that any other tool can read.

This guide describes the first public beta, 0.1.0-beta.1. New to Markise? Start with Getting started, then open Help → Tutorial in the app: a hands-on tour in a scratch document that never touches your own files.

Find your way

This is a beta

The beta is meant for real use, but expect rough edges and keep backups of important files. The most important limits, all described in the FAQ:

  • The builds are not code-signed, so the first launch needs an extra step (Getting started).
  • One document per window, no tabs, and no search across a whole folder yet.
  • PDF and PNG export show math and diagrams as source text; HTML export draws them.
  • Of the Mermaid diagram types, only flowcharts and sequence diagrams are drawn.

Shortcuts in this guide are written for macOS first; on Windows and Linux most of them use Ctrl where macOS uses Cmd. Help → Keyboard Shortcuts shows the exact keys on your system.
