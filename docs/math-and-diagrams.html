Math and diagrams

Math

Markise renders TeX math with a KaTeX-compatible engine that is built into the app; no internet connection or JavaScript is needed.

For example, $e^{i\pi} + 1 = 0$ gives , and this block:

$$
\int_0^1 x^2\,dx = \frac{1}{3}
$$

renders as

Format → Inline Math (Ctrl+M on macOS) inserts inline math. Chemistry formulas with \ce{…} (mhchem) work too.

If a formula has an error, Markise shows its TeX source in a warning colour instead of the rendering; fix the source and it renders again.

Diagrams

A fenced code block with one of these languages is drawn as a diagram:

A Mermaid flowchart:

```mermaid
flowchart LR
    Write --> Preview --> Share
```

A sequence diagram:

Edit the source in Source Code Mode or Side by Side and the diagram redraws.

Other Mermaid diagram types — class, state, Gantt, pie and so on — are not drawn yet. Markise shows their source with a note ("Mermaid diagram type … is not supported yet"), and the same fallback applies when a diagram has a syntax error, is too large, or takes too long to lay out.

Preferences → Markdown → Render diagrams turns diagram drawing off; the fences then stay code blocks.

In exports

  • HTML export contains math and diagrams as SVG pictures, so the file needs no scripts or fonts to show them.
  • PDF and PNG export show math and diagrams as their source text in the beta.
  • Pandoc formats receive math as native math (for example Word equations) and diagrams as code blocks.

See Export.
