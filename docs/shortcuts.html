Keyboard shortcuts

Help → Keyboard Shortcuts (Shift+Cmd+/, that is Cmd+?; on Windows and Linux Ctrl+Shift+/) lists every shortcut that is in effect on your system, including your own changes. Its search field finds commands by name, key or common alias ("bold" finds Strong).

The tables below list the default keys. A dash means the command has no default key; it is still in the menu.

Moving and selecting

Every movement key with Shift extends the selection.

Shortcuts by view

In Source Code Mode, and in the source pane of Side by Side, the Format and Paragraph commands are not available; typing, undo, selection and movement keys work as usual. Pressing the Source Code Mode shortcut in Side by Side switches to the full source view.

Change a shortcut

There is no shortcut editor yet. Add a "keyBinding" object to settings.json (see Settings) that maps a command's name or id to a key, and restart Markise:

{
  "keyBinding": {
    "Strong": "Ctrl+Shift+K",
    "Toggle Task Status": ""
  }
}
  • The command loses its default key; an empty string removes the key altogether.
  • If two commands get the same key, the later entry wins.
  • Unknown command names, keys that cannot be read, and system keys are ignored. Reserved on macOS: Cmd+H, Alt+Cmd+H, Cmd+M, Cmd+Q, Cmd+,, Cmd+Tab, Cmd+` and Cmd+Space; on Windows and Linux: Alt+F4 and Alt+Tab.
  • Editing and formatting commands can be changed this way. File, view and navigation commands (Quick Open, Close, zoom, Side by Side, Back and Forward, Keyboard Shortcuts) cannot be rebound yet.

Preferences → General → Custom key bindings shows the changes in effect.
